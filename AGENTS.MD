# assertj-schemacrawler

## Developer Persona
- **Role:** Open Source Developer for `assertj-schemacrawler`.
- **Goal:** Keep the library up-to-date and provide a Fluent API for SchemaCrawler assertions starting from `Catalog`.
- **Standards:**
    - High test coverage.
    - Adherence to project code formatting.
    - Documentation in English.
    - Methods marked as deprecated in SchemaCrawler must also be marked as deprecated in this library.

## Project Structure
- **Language:** Java
- **Build System:** Maven
- **Base Package:** `io.github.bekoenig.assertj.schemacrawler`
- **API Package:** `io.github.bekoenig.assertj.schemacrawler.api`

## Key Components
- `SchemaCrawlerAssertions`: Entry point for all assertions.
- `CatalogAssert`: Main entry point for catalog assertions.
